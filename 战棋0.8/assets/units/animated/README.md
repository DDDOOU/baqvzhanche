# 四方向单位序列帧

## `wp_light_tank_target_4dir_4f.png`（游戏当前使用）

- 用途：华约轻型坦克移动动画原型，目前接入 `T72B_TANK` 作为第一版实机验证素材。
- 纹理：128×128 RGBA 真透明 PNG。
- 单帧：原生32×32；运行时按照建筑层相同的 `2×zoom` 显示，世界尺寸仍为64×64。
- 来源：直接由 `art/source/wp_light_tank_target_master.png` 目标预览母版分格生成，不再使用测试用的简化坦克图。
- 清晰度：保留目标坦克的轮廓、炮塔、履带、阵营标记与明暗关系；使用与建筑层相同的32px原生帧和 `2×zoom` 显示方式。
- 排列：4列×4行。
- 列：待机接地、左履带推进、车体上浮1px、右履带推进。
- 行：右下（列+1）、左下（行+1）、左上（列-1）、右上（行-1）。
- 地面锚点：单帧 `(16,29)`。
- 世界尺寸：64×64地图单位；显示时只乘摄像机缩放，与地图保持绝对比例。
- Godot采样：项目全局使用 Nearest/最近邻，并启用2D像素对齐。

旧版贴图继续保留，方便对比或回滚。需要从目标母版重新生成当前图集时，运行
`tools/build_light_tank_target_atlas.ps1`。

后续坦克和车辆请沿用相同排布，这样只需在 `UnitRenderer.ANIMATED_UNIT_SHEETS` 中增加配置即可接入。

# 美术资产库 — Silent Reckoning 1987

冷战题材回合制战术战棋游戏 **Silent Reckoning 1987（静默行动）** 的美术资产库。

## 目录结构

```
美术资产库/
├── 01写实军事风/       # 写实风格卡牌面图 + 地形标记 + 结算背景
├── 02苏式粗犷风/       # 苏联构成主义/粗野主义风格 v2

```

## 风格说明

### 01 写实军事风
写实 Cold War 军事美学，暗色调战术风格。
- 卡牌面图（坐标预判、盲射弹幕、烟雾遮障、阵地加固、无线电静默、呼叫炮击、电磁反制）
- 地形标记（VP点、华约/NATO出生点、未知接触）
- 结算背景（胜利/失败）

### 02 苏式粗犷风
苏联构成主义 + 粗野主义风格，混凝土/锈铁/粗焊痕质感。
色调：锈红 + 灰 + 黑 + 赭黄。

### 坦克旋转动画
包含以下德军装甲单位（各 8 方向旋转帧）：
- Tiger I — 虎式重型坦克
- Panther — 黑豹中型坦克
- Panzer IV — 四号中型坦克
- Panzer II — 二号轻型坦克
- Hummel — 胡蜂自行火炮
- StuG III — 三号突击炮
- Sd.Kfz.251 — 半履带装甲车

每个单位包含分离层（Hull 车体 / Turret 炮塔）和合并版（Merged）。

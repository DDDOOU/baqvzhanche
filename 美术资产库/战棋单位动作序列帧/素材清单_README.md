# 战棋单位动作序列帧归档

归档内容对应 2026年8月24日“以 T-72B 为唯一像素标准重绘全部单位”的制作结果。

## 目录说明

- `01_游戏成品_128x128/`：50张可直接供 Godot 使用的移动、攻击序列帧。共25种单位，每种2张。
- `02_生成母版_24单位/`：24种重绘单位的独立高清生成母版。T-72B 沿用已经验收的原始素材，因此不包含在24张新母版中。
- `03_攻击特效_4帧/`：6张按武器类型复用的四帧攻击特效。
- `04_参考与说明/`：T-72B 基准图、动画配置、制作规范和全单位检查总览。

## 游戏成品规格

- 图片尺寸：128×128 PNG。
- 布局：4列×4行。
- 单帧尺寸：32×32。
- 方向行顺序：东南、西南、西北、东北。
- 地面接触点：单帧坐标 `(16,29)`。
- 像素设置：透明背景、近黑色轮廓、低色阶、无平滑与无抗锯齿。

## 使用建议

直接使用时，将 `01_游戏成品_128x128` 中的文件复制进 Godot 项目的单位动画目录，并保持文件名不变。`unit_animation_config.json` 记录了现有项目中的资源路径和播放参数。

需要重新制作某个单位时，参考 `04_参考与说明/README_制作规格.md`，替换对应母版后再运行项目中的重建工具。

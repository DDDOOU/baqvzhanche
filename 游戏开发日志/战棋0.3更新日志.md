# 战棋0.3 更新日志

日期：2026-08-06

## 版本定位

战棋0.3 是在战棋0.2.1 基础上的首个可菜单化试玩版本，重点补齐第一关场景内容、基础交互、卡牌操作、暂停与胜利进度显示，并整理中文文本编码问题。

## 场景与地图

- 填充第一关场景 `res://scenes/levels/level_01.tscn`。
- 基于 `assets/terrain/isometric_tileset.png` 设计草地、道路、森林、水域、泥地、建筑占地等不同地形。
- 将全局地图尺寸从 `20x15` 扩展为 `40x45`。
- 调整双方出生点布局，确保双方出生点距离超过 30 个单位。
- 添加并配置第一关双方基础兵种。
- 完成第一关加载与运行验证。

## 视角与输入

- 修复窗口缩放时场景不随窗口缩放的问题。
- 修复全屏显示异常，支持窗口正确全屏。
- 修复鼠标与键盘输入无效的问题。
- 为摄像头添加鼠标滚轮缩放功能。
- 为摄像头添加鼠标左键拖动地图功能。
- 添加鼠标悬停地块高亮提示。

## 单位、建筑与卡牌交互

- 鼠标悬停单位或建筑时显示名称。
- 为我方建筑和敌方建筑添加不同颜色高亮区分。
- 使用卡牌时，根据卡牌类型用不同颜色高亮作用范围。
- 单位移动增加确认步骤。
- 修复卡牌描述文本超出卡牌范围的问题，改为多行显示并限制在卡牌内。
- 添加卡牌栏展开/收起按钮，减少对场景的遮挡。
- 修复战报和控制台中的弃牌文本显示。

## 暂停、胜利条件与进度

- 添加暂停按钮。
- 暂停时仍可查看地图局势、单位和建筑，但不能操作。
- 添加胜利条件和完成进度显示。
- 将胜利条件/进度改为类似战报的半透明文本框样式，并缩小字号。

## 开始界面与关卡选择

- 新增开始界面。
- 新增关卡选择界面。
- 统一使用 `res://封面图.png` 作为开始界面和关卡选择界面的背景。
- 将按钮放置在窗口中下部，避免遮挡封面文字。
- 按钮文字改为白色加粗。
- 修复封面图显示方式，改为完整等比例显示，不再裁切。
- 项目启动入口改为菜单场景 `res://scenes/MainMenu.tscn`。

## 文本与编码

- 检索并修复项目内 UTF-8 被错误当成 GBK 读取后保存造成的中文乱码。
- 修复 `scripts/MainScene.gd` 中多处乱码注释。
- 修复 `scripts/ui/CardUI.gd` 中手牌 UI 乱码注释。
- 修复 `scripts/levels/LevelDatabase.gd` 中关卡事件文本：
  - `未知接触?` 调整为 `未知接触点`。

## 仓库整理

- 删除旧版本目录：`战棋`、`战棋0.1`、`战棋0.2`、`战棋0.2.1`。
- 将本地项目 `战棋0.2.1` 更名为 `战棋0.3`。
- 将 `战棋0.3` 作为当前主版本同步到 GitHub 仓库。

# 《静默行动·1987》玩法介绍

版本：1.0.0 正式版  
类型：像素风 2.5D 同步回合制战术战棋

## 游戏简介

1987 年，冷战前线的晨雾中出现了一支身份不明的机械化纵队。玩家将作为华约前线指挥官，在通信受阻、情报残缺和兵力有限的情况下，为装甲、步兵、侦察、防空与火炮单位制定行动计划，争夺战略据点并阻止北约部队突破防线。

本作的重点不是快速点击，而是在有限时间内判断敌情、规划路线、安排先后手，并承担每一道命令在沙盘演绎阶段产生的后果。

## 核心玩法

每个回合由两个阶段组成：

1. **计划阶段（60 秒）**：选择己方单位，规划移动、指定攻击目标或使用战术卡牌。完成部署后可以点击“结束计划”提前提交，不必等待倒计时结束。
2. **沙盘演绎阶段**：敌我双方按照统一行动顺序逐个执行命令。行动顺序优先参考单位的先手值，其次参考移动速度，因此同一回合中双方单位会交错行动。演绎过程中可以移动和缩放视角，也可以点击“跳过演算”缩短等待，但已经开始的动作仍会安全结算。

每支存活单位每回合拥有一个行动槽。玩家可以为其下达移动或指定攻击命令；具备移动后攻击能力的单位在移动完成后还会自动接敌，重型火炮等需要驻停的单位则不能在移动后立即开火。没有收到命令的单位会原地待命，并保留自动接敌能力。

## 地图与战术信息

- **蓝色地块**：当前单位本回合可以到达的位置。
- **白色路径**：鼠标悬停位置对应的最短路径预览。
- **绿色路径**：已经确认的移动路线；重新指定目标后旧路线会被替换。
- **红色地块**：建筑、不可通行地形或其他阻挡区域。
- **橙色目标**：当前可以直接攻击的敌方单位或区域。
- **VP 旗帜**：必须争夺和控制的战略目标。关卡胜负通常围绕这些区域展开。

建筑会占据地块，地面单位无法穿越，需要规划绕行路线。建筑遮挡单位时会适度虚化；烟雾会持续覆盖目标区域，将鼠标悬停在烟雾上可临时降低烟雾透明度以观察下方单位。

地图地块带有高度属性。攻击方处于高处时伤害提高，并更容易形成有效火力；从低处向高处攻击会受到惩罚。单位朝向同样重要：攻击侧面可获得约 35% 的伤害加成，攻击后方可获得约 50% 的伤害加成。

## 战争迷雾与侦察

未侦察区域及其中的敌军不会直接显示。侦察单位拥有更好的视野与机动能力，适合先行探路并确认未知接触。

战争迷雾不会缩短单位本身的移动范围；玩家可以命令单位进入尚未侦察的区域，并通过实际推进开拓视野。但未知敌军、地雷和突然出现的火力可能使原计划发生变化，因此盲目前进具有风险。

## 单位与战斗

战场单位包括指挥分队、步兵班、侦察分队、主战坦克、步兵战车、装甲输送车、反坦克小组、自行火炮、防空车辆和攻击直升机等。不同兵种在生命、装甲、穿透、射程、移动力、先手、视野、弹药与特殊能力方面各不相同。

- **侦察单位**：先手和机动能力较高，负责开拓视野与发现伏兵。
- **步兵与工兵**：适合复杂地形、据点防守、布雷和近距离作战。
- **坦克与步兵战车**：正面装甲和直射火力强，但需要注意侧后方暴露。
- **反坦克单位**：对装甲目标威胁极高，适合依托地形伏击。
- **火炮单位**：射程和范围杀伤出色，但通常需要驻停射击。
- **防空单位**：专门压制直升机等空中目标。

战斗会综合计算攻击力、装甲、穿透、射程、视线、地形高度、单位朝向、士气、EMI 与兵种克制。弹药耗尽、士气崩溃或关键单位被摧毁，都可能改变战局。

## 士气系统

士气分为昂扬、稳定、动摇和崩溃四档：

- 昂扬单位获得命中、防御和移动加成。
- 稳定单位保持正常战斗能力。
- 动摇单位命中与防御下降，并有小概率无法执行命令。
- 崩溃单位受到更严重的战斗惩罚，并可能在回合开始时陷入恐慌。

胜利、指挥官鼓舞可以提高士气；误伤友军、平民伤亡和剧情事件会造成士气损失。保存部队有时比消灭更多敌军更重要。

## EMI 电磁干扰

EMI 强度会随战役进程和特殊事件变化。干扰越强，电子设备效率越低，侦察范围和命中率越差，手牌也越可能变成无法预知效果的“乱码牌”。玩家需要观察左上角 EMI 指示，并决定是承受干扰、使用电磁反制，还是依靠传统侦察和直接火力完成任务。

## 战术卡牌与指挥点

玩家每回合拥有 5 点指挥点，用于发动共享战术卡牌。卡牌包括坐标预判、盲射弹幕、烟雾遮障、呼叫炮击、阵地加固、电磁反制、无线电静默、预备队投入、工兵布雷、牺牲冲锋、断电和战报谎言。

点击卡牌后选择地图目标即可使用；右键点击卡牌可以弃牌。炮击、烟雾和布雷等位置类效果会先在计划阶段标记，并在沙盘演绎阶段结算。部分强力卡牌具有冷却时间，错误目标不会消耗卡牌或指挥点。

卡牌不是单纯的额外伤害：烟雾可以压制敌军命中，阵地加固可以守住关键格，布雷可以封锁路线，而盲射弹幕虽然无视视野，却可能误伤友军。

## 第一关：边境晨雾

第一关要求玩家在第 8 回合结束时，控制三面 VP 旗帜中的至少两面。己方指挥中心被摧毁，或结算时控制的 VP 少于两处，则任务失败。

本关的关键机制为：

- 前 3 回合受晨雾影响，单位视野降低 3 格。
- 第 4 回合晨雾消散，视野恢复。
- 战争迷雾会隐藏未侦察区域与敌军位置。
- 第 3 回合可能出现北约空中增援。
- 第 5 回合起 EMI 开始增强。

建议先让侦察分队确认中路与 VP 周围的敌情，再让坦克和步兵战车占据能够互相支援的位置。不要在晨雾中随意使用范围射击；盲射能够压制未知区域，也可能造成友军误伤和士气损失。

## 基本操作

- **左键单击己方单位**：选择单位。
- **左键单击蓝格**：规划移动路线。
- **双击蓝格**：直接确认移动命令。
- **点击红色/橙色敌军**：指定攻击目标。
- **右键**：取消当前规划；在卡牌上右键可弃牌。
- **Enter**：确认移动；没有待确认移动时结束计划阶段。
- **Tab**：展开或收起卡牌栏。
- **W / A / S / D**：移动战场视角。
- **按住左键拖动地图**：拖拽战场视角。
- **鼠标滚轮**：以鼠标位置为中心缩放地图；指针位于战报内时用于滚动战报。
- **点击顶部行动顺序框**：将镜头定位到对应单位，并显示呼吸高亮环。
- **P**：暂停游戏，并可保存进度、进入设置或返回主菜单。
- **F11**：切换全屏显示。

## 新手建议

1. 先确认胜利条件和 VP 位置，再决定推进方向。
2. 用侦察单位开视野，不要让主力装甲单独进入未知区域。
3. 查看顶部行动顺序，优先处理即将行动的高威胁敌军。
4. 坦克正面对敌，利用道路快速机动，并避免暴露侧后装甲。
5. 将指挥点用于改变战局的关键位置，不必每回合把卡牌全部打出。
6. 晨雾、烟雾和高 EMI 环境下谨慎使用盲射，误伤会同时损失生命和士气。
7. 无法全歼敌军时，守住 VP 与指挥单位仍然可以赢得关卡。

# 2026-08-21 工作日志

## 战报面板无法滚动 Bug 修复
- **文件**: `scripts/ui/BattleLogUI.gd`
- **根因**: `log_label.mouse_filter = Control.MOUSE_FILTER_IGNORE` 把 RichTextLabel 设为忽略鼠标，导致滚轮事件无法接收，无法滚动查看历史战报。
- **修复**: 改为 `MOUSE_FILTER_PASS` —— 自身处理滚轮(可滚动)，事件继续传播(不挡棋盘点击)。
- **设计要点**: 父容器 BattleLogUI 保持 IGNORE(不挡棋盘点击)，子节点 RichTextLabel 用 PASS(可滚动且点击穿透)，两者分工。

## 战报滚轮仍缩放地图 — 二次修复（真正根因）
- **现象**: 第一次修复 mouse_filter 后，在战报上滚轮仍只缩放地图、战报不滚动。
- **真正根因**: `MainScene._input()` 的滚轮缩放逻辑用 `_is_pointer_over_interface()` 判断鼠标是否在 UI 上，但该函数只检查了按钮/卡牌面板/行动顺序条，**漏了战报面板**。导致滚轮事件在 `_input()` 阶段被地图缩放 + `set_input_as_handled()` 吞掉，GUI 阶段收不到事件，战报无法滚动。
- **关键认知**: Godot 中 `_input()` 先于 GUI 处理执行；在 `_input()` 里 `set_input_as_handled()` 会阻止事件到达 GUI。仅改 mouse_filter 不够，必须让 `_input()` 不抢占事件。
- **修复**: 
  1. `BattleLogUI.gd` 加 `get_panel_rect()` 暴露面板屏幕矩形
  2. `MainScene.gd` 加成员 `battle_log_ui` 持有引用（原来是丢弃的局部变量）
  3. `_is_pointer_over_interface()` 增加战报矩形判断
- **两个修复缺一不可**: mouse_filter=PASS(让面板能接收事件) + 界面判断(让 _input 不吞事件)。

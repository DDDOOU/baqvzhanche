# 边缘生成逻辑

## 坐标与处理顺序

地图方向以逻辑网格为准：`N=(0,-1)`、`E=(1,0)`、`S=(0,1)`、`W=(-1,0)`。先完成全部 `fill/rect/ellipse/path/polygon/scatter` 操作，只记录逻辑地形；最后统一解析图块。禁止在绘制过程中根据尚未完成的邻域选择边缘。

地图边界之外视为不同地形，因此贴近地图边界的区域会生成外边缘。

## 四邻域掩码

当前格与某方向邻格不同，则对应位为 1：`N=1`、`E=2`、`S=4`、`W=8`。

| 掩码 | 角色 | 含义 |
|---:|---|---|
| 0 | `center` | 四边均被同类地形包围 |
| 1/2/4/8 | `edge_n/e/s/w` | 单边暴露 |
| 3/6/12/9 | `corner_ne/se/sw/nw` | 两条相邻边暴露 |
| 5/10 | `channel_ew/ns` | 两条相对边暴露，形成狭道 |
| 14/13/11/7 | `cap_n/e/s/w` | 仅向一个方向连接 |
| 15 | `isolated` | 四边均暴露 |

## 水域方位表

| 角色 | Atlas 坐标 | 唯一视觉名称 |
|---|---|---|
| `edge_n` | `(0,8)` | 浅水波纹·北缘长波 |
| `edge_e` | `(1,9)` | 浅水流纹·窄幅右摆 |
| `edge_s` | `(1,8)` | 浅水波纹·南缘长波 |
| `edge_w` | `(0,9)` | 浅水流纹·宽幅左摆 |
| `corner_ne` | `(3,8)` | 浅水波纹·东北双层回旋 |
| `corner_se` | `(3,9)` | 浅水涟漪·东南双圈 |
| `corner_sw` | `(2,9)` | 浅水涟漪·西南单圈 |
| `corner_nw` | `(2,8)` | 浅水波纹·西北中央圆波 |
| `channel_ew` | `(4,8)` | 中水波纹·东西狭道 |
| `channel_ns` | `(5,8)` | 中水波纹·南北狭道 |
| `cap_n/e/s/w` | `(4,9)/(5,9)/(4,8)/(5,8)` | 对应方向的中水端头 |
| `isolated` | `(2,8)` | 浅水波纹·孤立水洼 |
| `center` | `(7..8,8..9)` | 深水波纹或深水涟漪 |

例如水域西侧边缘格的西邻格不是水域，掩码包含 `W=8`；没有其他暴露边时角色为 `edge_w`，固定使用 `(0,9) 浅水流纹·宽幅左摆`。

## 回退规则

只有在方位表中存在专用素材时才启用边缘选择。没有完整边缘素材的草地、森林、灌木、岩地和道路继续使用其中心变体；不得通过旋转不对称像素图块来伪造缺失方向。新增素材后，先给每个方向分配唯一名称和 atlas 坐标，再加入生成器的 `EDGE_AWARE_TILES`。
